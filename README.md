# 🧠 AI Agent Debator

An interactive AI debate platform where multiple AI agents engage in structured debates on various topics, while a third AI agent acts as the **judge**, evaluating and scoring their arguments.  
Built with **Next.js** for the frontend and powered by intelligent AI agent interactions.

---

## 🚀 Features

- 🤖 **Multi-Agent Debate System using Langchain** — Two AI agents argue from opposing sides on a chosen topic.  
- ⚖️ **AI Judge** — A third AI agent objectively evaluates the debate and declares a winner.  
- 🧩 **Customizable Topics** — Users can input or select topics for debate.  
- 💬 **Dynamic Dialogue Display** — Real-time updates of AI exchanges with smooth animations.  
- 🎨 **Modern Frontend** — Built using **Next.js**, **TailwindCSS**, and clean UI components.  
- 🧠 **LLM-Powered Reasoning** — Each agent uses distinct reasoning chains and styles for engaging debates.
