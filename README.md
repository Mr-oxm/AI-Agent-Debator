# 🤖 AI-Agent-Debator

An AI-powered debating system where autonomous agents engage in structured debates on any topic.  
Built to explore reasoning, argumentation, and counter-argument generation using LLMs.

---

## 🚀 Features

- 🧠 AI agents generate and exchange arguments on chosen topics  
- 🔁 Multi-round debate structure (opening, rebuttal, conclusion)  
- ⚙️ Configurable debate parameters (topic, stance, number of rounds)  
- 🧩 Modular design — easy to extend or integrate into other apps  
- 💬 Optional UI for live debate visualization
